GitHub Pagesで公開する手順

1 このコードをファイルとして保存

このページの完全なコードを index.html という名前でパソコン上に保存します。

2 GitHubリポジトリを作成 & プッシュ

  1. GitHubにログインし、新しいPublic（公開）リポジトリを作成します。
  2. 作成したリポジトリに index.html をコミット・アップロードします。

3 GitHub Pagesを有効化

リポジトリの Settings > Pages を開き、Sourceを main (or master) branch に設定してSaveします。数分でURLが発行されます。

4 Firebase Authenticationの「承認済みドメイン」に追加

Googleログインを有効にするため、Firebase Consoleの Authentication > Settings > Authorized domains に、GitHub Pagesのドメイン（例: username.github.io）を追加してください。
